# AymaneMaki_FinalProject_Html-CSS
ATHAR (أثر)

ATHAR (أثر) is a confidential, human-centered web platform dedicated to supporting and empowering women affected by violence. Built with warmth, clarity, and dignity, it connects survivors with psychological care, legal guidance, professional empowerment, community stories, and direct support resources.

Pages & Structure

index.html / home.html: Main landing pages introducing ATHAR's mission, core values, and an overview of the four support pathways (Psychological Support, Legal Support, Professional Empowerment, and Group Support Meetings).

programs.html: Detailed breakdown of the four support tracks, available workshops, legal orientation, and direct request actions.

stories.html: Survivor stories across Video, Audio, and Written formats (e.g., "Shaping clay, shaping a new life", "The first morning I felt safe", "Letters to my younger self"), paired with educational resources and the Community Solidarity Wall.

contact.html: Confidential support and appointment request form, emergency contact information, center details, and support directory.

Design System & Visual Identity

Direction & Layout: Left-to-Right (dir="ltr") desktop-first responsive layout designed for readability, calm navigation, and emotional safety.

Typography: Classic Serif typography across headings and editorial sections to create a warm, trustworthy, and human-centered tone.

Color Palette:

Warm Cream (#F6F1E7 / #FAF7F0): Primary page backgrounds and light card surfaces.

Deep Olive (#4A4D3E): Main headings, body text, and structural contrast.

Soft Sage (#9EA384 / #E4E7D7): Section bands, story action buttons (Play Video Story, Listen to Audio, Read Story), and organic background shapes.

Terracotta Orange (#C85D32 / #E27227): Primary call-to-action buttons (Request Psychological Support, Get Support) and bold section headlines ("Together, we create change.").

Getting Started

Clone or download the project repository.

Ensure your compiled Tailwind CSS, daisyUI, and Bootstrap Icons assets are properly linked.

Open index.html in your browser or run a local server (such as VS Code Live Server at http://127.0.0.1:5500) to preview all pages.
